This project explores trends in Netflix movies and TV shows by analyzing genres, ratings, release years, and global content distribution.

🔍 Key insights from the dashboard:
* 8800+ titles analyzed
* Movies dominate the platform with ~70% share
* Content production grew rapidly after 2015
* Drama and International Movies are among the most common genres

📊 Tools used:
Power BI | DAX | Data Visualization | Data Cleaning
